# CORE AITU — управление сообществом

Этот репозиторий — публичная рабочая память CORE: участники, подтверждённые результаты, планы, события и простые правила публикации. Здесь хранятся Markdown-документы и ссылки на материалы; исходники дизайна, большие видеофайлы и закрытые данные находятся в соответствующих ресурсах.

Сейчас документы содержат структуру и шаблоны. Факты о людях, прошедших событиях и адреса каналов добавляются после проверки.

| [Вклад](contributions.md) | Конкретные результаты и ссылки на подтверждения |
| [Ресурсы](resources.md) | Назначение репозиториев, каналов и хранилищ |
| [Планы](plans.md) | Общие задачи и ближайшие шаги |

## Как обновлять

1. Запишите новую общую задачу в [планы](plans.md) или задачу конкретного события в его карточку в [событиях](events.md). Укажите ответственного, если он уже согласован.
2. До анонса заполните карточку события, подготовьте материалы по [регламенту](handbook.md) и возьмите текст из [шаблонов](templates.md).
3. После события добавьте ссылки на публикации и результат в ту же карточку, затем зафиксируйте подтверждённый вклад людей в [журнале](contributions.md).
4. Раз в месяц соберите из карточек и журнала [отчёт для ДСВР](templates.md#ежемесячный-отчёт-для-дсвр).

Документы преимущественно на русском; английские термины и двуязычные фрагменты допустимы, когда они помогают аудитории. Для дат используем `ГГГГ-ММ-ДД`, для незаполненных сведений — `[уточнить]`. Перед публикацией итогового текста удаляем такие пометки. Не размещаем здесь пароли, закрытые ссылки, личные контакты без согласия и неподтверждённые обещания от имени AITU.

Все задачи ведутся в Markdown. Если карточек событий станет слишком много для одного файла, [events.md](events.md) останется указателем, а карточки будут перенесены в файлы по месяцам с сохранением их номеров.
