# gov

Этот репозиторий содержит наши рабочие аспекты CORE про участников из staff, результаты ивентов, планы на будущее со статусами, публикации, шаблоны, и документации, и простые правила. Вся текстовые записи ведутся в Markdown формате, а отдельные крупные ресурсы и внешние материалы в виде ссылок. Пока что некоторые вещи описаны довольно поверхностно, но постепенно будут дополняться и более подробнее рассматриваться. 

Текущая структура данного репозитория представлена ниже:
```
- staff.md - основной активный состав, базовая плоская иерархия, их примерные гибкие зоны ответственности, и подтвержденные результаты деятельности как вклад в сообщество.
- resources.md - обозначение резервных хранилищ материалов, каналов связи, назначение репозиториев, и ответственных за них.
- operations.md - трекинг уже проведенных событий за все время и планирование необходимых задач.
- handbook.md - описывает различные формальные регламенты, шаблоны отчетности и публичных постов, набор инструментов, промпты для ai сервисов, ответы на вопросы и помощь по ситуациям.
- /scripts - вспомогательные скрипты например для сортировки и выгрузки отчетов.
- /assets - временные ассеты по типу сжатых изображений для отчетов.
```
