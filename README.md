# CORE governance

Рабочая документация сообщества CORE: состав staff, правила работы, ресурсы,
операционные планы и подтверждённые результаты. Репозиторий не является
реестром персональных данных: публикуйте только те контакты и сведения, на
которые участник явно согласился.

## Навигация

| Документ | Назначение |
| --- | --- |
| [staff.md](staff.md) | Состав staff, модель управления и вклад участников |
| [operations.md](operations.md) | Планирование, проведение и архив событий |
| [handbook.md](handbook.md) | Регламенты, шаблоны отчётности и инструкции |
| [resources.md](resources.md) | Каналы, репозитории и правила хранения |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Как предлагать изменения в документации |

`assets/` содержит только небольшие материалы, необходимые для
документации. Большие исходники и резервные копии хранятся во внешних
хранилищах, перечисленных в `resources.md`.

## Принципы

- фиксируем решения и результаты, а не только намерения;
- назначаем ответственному задачу и ожидаемый результат;
- не публикуем секреты, лишние персональные данные и приватную переписку;
- обновляем ссылки и статусы, когда меняются каналы или договорённости.
