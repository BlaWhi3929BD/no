# Вклад в документацию

## Как предложить изменение

1. Создайте отдельную ветку от `main`.
2. Внесите небольшое тематическое изменение в Markdown.
3. Проверьте ссылки, имена файлов и отсутствие секретов или лишних
   персональных данных.
4. Откройте pull request с описанием причины и ожидаемого результата.

Для срочных исправлений допустим прямой коммит после проверки другим
участником staff.

## Правила содержания

- Пишите коротко и конкретно, указывайте ответственного и срок для задач.
- Используйте единый формат дат `ДД.ММ.ГГГГ`.
- Не добавляйте приватные контакты, скриншоты переписок, токены и ключи.
- Для нового процесса обновляйте и индекс, и соответствующий раздел handbook.
- Завершённые задачи должны содержать ссылку на подтверждение или объяснение,
  почему подтверждение недоступно.
